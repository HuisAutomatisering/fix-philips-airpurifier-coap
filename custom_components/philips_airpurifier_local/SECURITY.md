# Security Policy

## Supported versions

Only the latest release of this integration receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.
Use GitHub's private vulnerability reporting instead:
[Report a vulnerability](https://github.com/HuisAutomatisering/fix-philips-airpurifier-coap/security/advisories/new).

You can expect a first reaction within a couple of weeks. This is a hobby project
maintained in spare time.
